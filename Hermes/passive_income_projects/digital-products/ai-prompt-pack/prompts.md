# AI Prompt Engineering Master Pack

## Category 1: Content Creation

### Prompt 1: Viral Blog Post Generator
You are an expert content strategist. Write a viral blog post about [TOPIC] targeting [AUDIENCE]. Structure: Hook, Problem statement, Solution overview with 3-5 key points, Detailed breakdown, Actionable takeaways, Strong conclusion with CTA. Tone: PROFESSIONAL/CONVERSATIONAL/EDUCATIONAL. Length: 1500-2000 words.

### Prompt 2: Newsletter Copy That Converts
Write a newsletter edition for [TOPIC] with the goal of educate/sell/engage. Include 3 subject line variants, personal opening, key insight, supporting detail, CTA, and PS with bonus value.

### Prompt 3: Social Media Thread Architect
Create a Twitter/X thread about [TOPIC] that goes viral. Hook under 240 chars, 8-12 tweets, each adds value, bridge tweet at position 4-5, strong final tweet with retweet CTA.

### Prompt 4: SEO Article Writer
Write an SEO-optimized article targeting keyword [KEYWORD]. Include title tag under 60 chars, meta description under 160 chars, H1 with primary KW, H2 sections with secondary KWs, FAQ section, keyword density 1-2%.

### Prompt 5: Email Sequence Builder
Create a 5-email welcome sequence for a product/service. Email 1: Welcome + value. Email 2: Story. Email 3: Social proof. Email 4: Objections. Email 5: Offer + urgency.

### Prompt 6: Video Script Structure
Write a video script for a [LENGTH] video about [TOPIC]. Hook (first 5 seconds), Intro, 3 main points with transitions, Summary, CTA. Include visual/audio notes for each section.

### Prompt 7: Landing Page Copy
Write high-converting landing page copy for [PRODUCT]. Hero section, problem/agitate/solve, features as benefits, social proof, FAQ, risk reversal, CTA. Follow proven conversion frameworks.

### Prompt 8: Case Study Template
Create a case study framework for [CLIENT RESULT]. Background, Challenge, Solution, Results (with metrics), Testimonial, Lessons learned. Use before/after format.

### Prompt 9: Product Description Optimizer
Rewrite this product description to maximize conversions: [PASTE DESCRIPTION]. Include sensory words, social proof triggers, scarcity elements, benefit-first structure, and a compelling CTA.

### Prompt 10: Press Release Writer
Write a press release about [NEWS/ANNOUNCEMENT]. Follow AP style. Include headline, dateline, lead paragraph (who, what, when, where, why), body with quotes, boilerplate, and media contact info.

## Category 2: Business & Strategy

### Prompt 11: Business Model Canvas Analyzer
Analyze this business model using the Business Model Canvas framework: [DESCRIBE BUSINESS]. Evaluate: Value Proposition, Customer Segments, Channels, Customer Relationships, Revenue Streams, Key Resources, Key Activities, Key Partnerships, Cost Structure.

### Prompt 12: Competitor Analysis
Perform a deep competitive analysis for [INDUSTRY/MARKET]. Identify top 5 competitors, their market share, unique value props, pricing, strengths, weaknesses, and strategic gaps I can exploit.

### Prompt 13: SWOT Analysis Generator
Generate a SWOT analysis for [COMPANY/PRODUCT]. Include internal factors (Strengths, Weaknesses) and external factors (Opportunities, Threats). Prioritize each item by impact and provide strategic recommendations.

### Prompt 14: Go-to-Market Strategy
Create a go-to-market strategy for [PRODUCT] targeting [SEGMENT]. Include: target persona, messaging, channel strategy, launch timeline, success metrics, and budget allocation.

### Prompt 15: Pricing Strategy Consultant
Analyze optimal pricing for [PRODUCT TYPE] in [INDUSTRY]. Consider: value-based pricing, competitor pricing, cost-plus, freemium models, tiered pricing, and psychological pricing tactics.

## Category 3: Coding & Development

### Prompt 16: Code Review Specialist
Review this [LANGUAGE] code for: bugs, security vulnerabilities, performance issues, code style violations, and architectural concerns. Provide specific line-numbered feedback and suggested fixes.

### Prompt 17: Bug Hunter
Analyze this error/bug: [DESCRIBE/PASTE ERROR]. Identify likely causes, suggest debugging approaches, provide potential fixes, and recommend preventative measures.

### Prompt 18: API Documentation Writer
Generate comprehensive API documentation for [ENDPOINT/DESCRIPTION]. Include: endpoint URL, method, request parameters, response format, error codes, example requests/responses, and authentication requirements.

### Prompt 19: Test Case Generator
Generate unit tests for [FUNCTION/CLASS]. Cover: happy path, edge cases, error conditions, boundary values, and performance considerations. Use [TESTING FRAMEWORK] conventions.

### Prompt 20: Architecture Reviewer
Review this system architecture: [DESCRIBE]. Evaluate: scalability, reliability, security, cost efficiency, maintainability, and alignment with best practices. Provide specific improvement recommendations.

## Category 4: Marketing & Growth

### Prompt 21: Growth Channel Analyzer
Analyze growth channels for [PRODUCT/BUSINESS]. Evaluate: SEO, content marketing, paid ads, social media, email marketing, referrals, partnerships, viral loops, and community building. Score each by: cost, effort, scalability, and conversion potential.

### Prompt 22: Content Calendar Planner
Create a 30-day content calendar for [NICHE/PLATFORM]. Include: content themes, formats (article/video/infographic), publishing schedule, promotion plan, and KPI targets.

### Prompt 23: Funnel Optimizer
Analyze this conversion funnel: [DESCRIBE FUNNEL]. Identify drop-off points, suggest improvements for each stage, recommend A/B test ideas, and estimate impact of each change.
